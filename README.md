# QBR

Quarterly Business Reports, as a card game: a grid-territory card battle on a 3x5
spreadsheet, headed toward a Balatro-style run of meetings, jokers and shortcuts.
See `CLAUDE.md` for the rules, the Phase 0 measurements and the roadmap.

```
pnpm install && pnpm dev      # http://localhost:5176
pnpm test && pnpm measure
```
